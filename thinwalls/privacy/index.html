밤손님 개인정보 처리방침

VyxWorks(빅스웍스)가 제공하는 ‘밤손님’은 게임 이용 정보를 수집하거나 외부 서버로 전송하지 않습니다.

기기에 남는 정보

근무 진행, 승진·체포 기록, 비품, 오늘의 동 기록과 소리·햅틱 설정은 기기의 앱 저장 공간에만 보관합니다. 회원가입, 광고, 이용 분석, 추적 기능은 없습니다.

보급권 구매

결제는 Apple의 App Store가 처리합니다. 밤손님은 결제 수단 정보를 받지 않습니다. 보급권 잔액과 중복 지급을 막는 거래 번호는 기기의 보안 저장 공간에 보관하며 운영자 서버로 전송하지 않습니다. 다른 기기로 잔액을 이전할 수 없습니다.

기록 지우기

앱 설정의 ‘기록 초기화’로 누적 진행 기록을 초기화할 수 있습니다. 저장된 근무와 설정은 앱을 삭제하면 지워집니다. 보급권과 거래 기록은 같은 기기에서 다시 사용할 수 있도록 앱 삭제 후에도 보안 저장 공간에 남을 수 있습니다. iOS 기기 백업에 포함된 데이터는 기기의 백업 설정에서 별도로 관리할 수 있습니다.

직접 공유할 때

‘오늘의 동’ 기록증은 사용자가 공유 버튼을 눌러 선택한 앱으로만 전달됩니다. 공유 이후의 처리는 해당 앱의 개인정보 처리방침을 따릅니다.

문의할 때

사용자가 이메일 문의를 보내면 회신 주소와 문의 내용을 문제 해결과 답변에 사용합니다. 문의 해결 후 더 보관할 필요가 없는 내용은 삭제합니다. 법령에 따라 보관해야 하는 경우에는 해당 기간을 따릅니다.
